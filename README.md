# 📱 Cartão de Visitas Digital

Um cartão de contatos e links estilo "Link na Bio", limpo, moderno e 100% responsivo. Desenvolvido em HTML e CSS puro para hospedagem gratuita no GitHub Pages e integração com cartões NFC ou QR Codes.

## 🚀 Recursos

- **Mobile-First:** Design moderno e otimizado para navegação em smartphones.
- **Sem Dependências:** Construído em HTML5 e CSS3 puros (sem frameworks pesados).
- **Ações Rápidas:**
  - 💬 Conversa direta no WhatsApp sem necessidade de adicionar aos contatos.
  - 🔑 Copia de chave Pix para a área de transferência com um clique.
  - 📇 Baixa o cartão de visitas (.vcf) direto para a agenda do celular.

## 🛠️ Como Personalizar

1. Abra o arquivo `index.html`.
2. Substitua a URL da tag `<img>` pela foto do seu perfil.
3. Atualize o nome e a breve biografia.
4. Insira seus dados reais nos links (`wa.me`, perfis de redes sociais e chave Pix).

## 🌐 Como Hospedar Gratuitamente

1. Faça o upload dos arquivos `index.html` e `README.md` para o seu repositório.
2. Acesse a aba **Settings** do repositório no GitHub.
3. Vá até a seção **Pages** no menu esquerdo.
4. Em **Branch**, altere para `main` (ou `master`) e clique em **Save**.
5. Em poucos instantes, sua página estará no ar na URL exibida na tela.

---

💡 *Dica: Copie o link gerado pelo GitHub Pages para criar seu QR Code ou gravar em uma tag/cartão NFC com o aplicativo **NFC Tools**.*
